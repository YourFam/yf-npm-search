# yf-npm-search

Unscoped alias of [`@yourfam/yf-npm-search`](https://www.npmjs.com/package/@yourfam/yf-npm-search). Same command (`yf-npm-search`), same version.

```bash
npx yf-npm-search --help
```

Install the scoped package if you can; this name exists so `npx yf-npm-search` cannot be taken by someone else.
